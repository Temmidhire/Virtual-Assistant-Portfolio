# Temidire Ogunbekun — VA Portfolio

A GitHub Pages-ready portfolio for Virtual Assistant, Executive & Administrative Support, Data & Research work.

## Publish on GitHub Pages
1. Create a new GitHub repository, e.g. `va-portfolio`.
2. Upload **all files and the `assets` folder** from this package.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your public Pages URL.
